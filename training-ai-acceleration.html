From script to agent

Three stages. Take as many as you need.

The visible part is the script. Most of the value sits below the waterline.

STAGE 1

Script & AI chat

Rigid Python for pre and post-processing and DoE. An AI chat writes the pwpy code with the API documents and examples in context.

STAGE 2

AI agent

Claude Code or Codex runs the machine: folders, GPU jobs, retries. It calls Blender or Paraview.

STAGE 3

Review, learn, extend

The agent checks the results, remembers your best practices, and goes as far as an SDK hook inside the solver.

What you leave with

Six working pieces, not slides

  • A gearbox thermal chain from churning run to temperatures
  • A materials DoE across Newtonian, Bingham and shear-thinning laws
  • An automatic report same format for every run
  • A Blender render pipeline particles to beauty frames
  • A scripted motion keyframes without clicking
  • A custom viscosity law up to an SDK hook in the solver
